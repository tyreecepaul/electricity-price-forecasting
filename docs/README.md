## Preparing deliverables

The proposal should explain the problem, its significance and why the work is
feasible. The seminar should present the method, findings, limitations and
conclusion with enough evidence to support the claims.

The report should document the data, chronological splits, features, model
settings and evaluation so results can be reproduced. Include each member's
contribution and acknowledge outside assistance. The template permits at most
5 appendix pages and includes a teaching-resource consent statement that the
group must resolve before submission. The course notes also require a separate
code ZIP submission.

The reflective essay is individual: describe your contributions, decisions,
difficulties and lessons, rather than repeating the group report.
Contribution statements are also individual submissions. Use the current
course submission links, and state how AI tools were used in the assessment
deliverables, as required by the project brief.
